# Cheapest Flight Finder

## Project Overview
A web application where users enter a departure and destination city, and the app displays available flight options sorted by price.

The application fetches data from a public API and processes it to simulate flight listings, allowing users to view the cheapest flights between two locations.

---

## Features
- Fetch data from a public API using fetch
- Display multiple flight options
- Sort flights from lowest to highest price
- Filter flights based on route (departure → destination)
- Search functionality for airlines
- Responsive design for mobile and desktop

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## How It Works
1. Fetch data from the API
2. Transform data into flight objects using map()
3. Filter flights based on user input using filter()
4. Sort flights by price using sort()
5. Display results dynamically on the webpage
